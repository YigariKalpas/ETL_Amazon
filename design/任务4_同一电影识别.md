# 任务4 同一电影识别（首版实现）

> 实现：crawler/movie_entities.py（规则版本 movie_entities/v1）。
> 输入：972 个已解析作品页（film/series/concert/anime/boxset 五族），来自 1,054 个成功页中的作品类。
> 输出：data/staging/entities/（movie / product_edition / product_movie / merge_decision / review_queue / boxset_candidates / summary）。

## 一、操作性定义

| 概念 | 定义 |
|---|---|
| movie_id | 一个创作作品。同一作品的不同载体、语言、地区、包装版本共享同一 movie_id |
| edition | 商品级记录（ASIN），保留载体、语言、碟数、厂牌、商品发售日与快照哈希 |
| 关系类型 | single（单商品）/ same_work_edition（跨版本）/ series_volume（剧集卷季）/ boxset_member（合集成员，待人工确认） |

合并边界（作业要求）：重拍片、续集、同名不同作品分别建模；剧集与电影不混算；合集是 Product↔Movie 多对多，评论留在商品上。

## 二、规则与阈值

| rule_id | 条件 | 判定 | 置信度 |
|---|---|---|---|
| A-MULTI-FEATURE | 标准化标题完全相等 且（导演一致 或 演员交并比 ≥0.6）且 片长差 ≤10 分钟 | 自动合并 | 0.6–0.8 |
| A-TITLE-RUNTIME | 标准化标题完全相等 且 片长差 ≤10 分钟 且 载体不同 | 自动合并 | 0.70 |
| A-TITLE-RUNTIME-FUZZY | 标题相似度 ≥0.90 且 片长差 ≤10 分钟 且 载体不同 | 自动合并 | 0.62 |
| S-SERIES-ROOT | 剧集族内根标题相同（剥离 Season/Vol./Episode 后） | 归入同一 series 实体 | 规则级 |
| M-PARTIAL | 标题相似度 0.86–1.0 但证据不足 | 人工复核 | 0.47–0.57 |
| R-DIRECTOR | 导演明确不同 | 不合并 | — |
| R-YEAR-CONFLICT | 标题内年份证据冲突 | 不合并 | — |
| R-RUNTIME | 片长差 >25 分钟 | 不合并 | — |
| R-FAMILY | 不同作品族（如电影 vs 剧集 / 音乐） | 不合并 | — |
| R-WEAK | 相似度 <0.86 且无任一强特征 | 不合并（留痕） | — |
| H-REVIEW-ACCEPT / REJECT | 人工复核结论回灌 | 合并 / 不合并 | 0.9 / 0.95 |

关键取舍：**单特征不足以自动合并**（作业明文要求）。因此标题相同但缺导演/演员/片长的对子一律进复核队列，不自动合并。

第 2、3 条正是作业说的「包装相同但作品不同」的陷阱：Criterion Collection 字样拉高标题相似度，必须靠作品级证据拦截。

## 六、人工复核闭环

1. 打开 data/staging/entities/review_queue.csv（4 行待判，含标题、相似度、演员交并比、片长差、置信度）；
2. 在最后一列 human_decision 填 accept 或 reject；
3. 回灌重跑：

    .venv\Scripts\python.exe crawler\movie_entities.py --apply-review data\staging\entities\review_queue.csv

接受记 H-REVIEW-ACCEPT，拒绝记 H-REVIEW-REJECT，两者都写回 merge_decision.csv 并影响 summary.json 的合并簇。这样「支持检查和纠正误合并」是闭环，不是口头承诺。

## 七、与作业条款的对照

| 作业要求 | 实现情况 |

| 三级判定 + 证据 + 阈值 + 版本 | ✅ merge_decision.csv 含全部证据列与 rule_id |
| 聚类一致性检查 | ✅ 合并前检查簇内导演唯一、片长极差 ≤25 分钟，冲突则降级 review |
| 合并前后数量与映射历史 | ✅ summary.json 记录 clusters_total / merged / products_merged |
| 5 组合并 + 5 组未合并实例 | ✅ 5 组合并、6 组未合并 |

## 八、已知限制

1. 缺上映年份：页面只有商品发售日，release_year 留空；部分标题方括号里带年份（如 [1992]），只作证据，不作合并依据；
2. 样本小：972 个作品里跨版本重复仅 3 组，报告中必须说明这不能外推全量；
3. 合集成员来自标题枚举，未枚举的合集（26 − 10）只能标 contents_unknown；
4. 人物层（任务5）未做，合并暂用姓名字符串比对，未使用人物实体；
5. 置信度是经验标度，尚未在标注集上校准；作业要求的评价集与开发样本分离，留待任务5/总评阶段。
