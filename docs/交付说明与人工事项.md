## 三、A 抽样分类复核（27 行）

文件：`data/staging/audit_sample.csv`，列：

    asin, 分类, 标题, breadcrumb首层, 媒体格式, 厂牌, 时长(分), 演员数, 快照路径, 人工结论(待填)

**只填最后一列**，取值四选一：`正确` / `分类错` / `字段错` / `无法判断`。

判定规则（照此填，不用自己定口径）：

| 看什么 | 判正确 | 判错误 |
|---|---|---|
| 分类 vs 标题 | 单片电影→movie；带 Season/Vol./Episode→series；演唱会碟→concert | 剧集被判成 movie |
| 分类 vs 面包屑 | Movies & TV 且属作品类 | Books/Toys 却判 movie |
| 时长 | 电影 80-180 分钟 | 单集却 400 分钟（合辑当单集） |
| 演员数 | 与页面 byline 一致 | 只截了前 3 位当全部 |
| 缺字段 | 页面本身没有 → 客观缺失（不算错） | 页面有却没抽到 → 字段错 |

示例行（前 3 行填好后长这样）：

    0780622243,movie,Deconstructing Harry [DVD],Movies & TV,...,正确
    0764005189,movie_weak,Fantastic Planet [VHS],Movies & TV,...,正确
    6301934008,series,"Fraggle Rock, Vol. 13 - Marooned [VHS]",Movies & TV,...,无法判断

填完告诉我错误率口径即可，我在报告里写：抽样 27 条、判错 N 条、错误率 X%。

## 四、B 合并候选复核（53 行）

文件：`data/staging/entities/review_queue.csv`，列：

    asin_a, asin_b, title_a, title_b, title_ratio, cast_jaccard, runtime_delta, year_a, year_b, confidence, human_decision(accept/reject)

**只填最后一列**：`accept`（是同一作品）或 `reject`（不是）。

判据（按顺序看）：

1. 标题是否只差版本标记（VHS/DVD/Blu-ray/Import/Vol.）→ 倾向 accept；
2. 片长差 ≤10 分钟 → 支持 accept；差 >25 分钟 → reject；
3. 演员交并比 ≥0.6 → 支持 accept；为 0 且无其他证据 → 倾向 reject 或“无法判断”（留空即待定）；
4. 同名但导演明确不同（如 Zorro 1920 vs 1998）→ reject。

回灌命令（填完后运行）：

    .venv\Scripts\python.exe crawler\movie_entities.py --apply-review data\staging\entities\review_queue.csv
    .venv\Scripts\python.exe crawler\coverage_report.py
