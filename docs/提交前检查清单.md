## 五、提交前 15 分钟标准流程

1. 暂停采集：写 data\crawler\STOP，等 30 秒；
2. 跑第一节的 10 项检查，记录结果；
3. 如需幂等证明，跑 idempotency_check（约 5 分钟）；
4. 重新生成可视化：export_viz.py + build_dashboard.py；
5. 更新报告数字：coverage_report.py、db_inventory.py、status_report.py；
6. 检查 git status，确认没有把 data/ 或临时文件带进来；
7. 本地提交由你执行（本会话约定：git 写操作由用户本人完成）；
8. 推送 develop（命令行推送在本机不可用，请用 GitHub Desktop）。
